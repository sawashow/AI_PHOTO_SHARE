# ルーティング設計

URL と HTTP メソッドの対応です。各画面に出す内容と画面同士の移動は [screen-design.md](screen-design.md) に書きます。機能の範囲は [requirements.md](requirements.md) に従います。

いいね用のルートは作りません。コメント用のルートも今回は作りません。

## ルート一覧

| メソッド | パス | 処理 | ログイン | 成功したとき | 失敗したとき |
|---|---|---|---|---|---|
| GET | `/` | 投稿一覧を表示する | 不要 | 一覧を表示する | 取得に失敗したらエラーを出し、空の成功画面にしない |
| GET | `/register` | 登録画面を表示する | 不要 | 登録画面を表示する | |
| POST | `/register` | ユーザーを登録する | 不要 | `/login` へ移す | 登録画面に残り、理由を出す |
| GET | `/login` | ログイン画面を表示する | 不要 | ログイン画面を表示する | |
| POST | `/login` | ログインする | 不要 | `/` へ移す | ログイン画面に残り、理由を出す |
| POST | `/logout` | ログアウトする | 必要 | `/` へ移す | 未ログインなら処理せず `/` へ移す |
| GET | `/posts/new` | 投稿作成画面を表示する | 必要 | 投稿作成画面を表示する | 未ログインなら `/login` へ移す |
| POST | `/posts` | 写真とキャプションを保存する | 必要 | `/` へ移す | 未ログインなら `/login` へ移す。入力が無効なら投稿作成画面に残り、理由を出す |
| GET | `/posts/<id>` | 投稿詳細を表示する | 不要 | 詳細を表示する | その id の投稿がなければ、見つからない旨と一覧へ戻るリンクを出す |
| POST | `/posts/<id>/edit` | 自分のキャプションを保存する | 必要 | `/posts/<id>` へ移す | 下記の「修正と削除」を参照 |
| POST | `/posts/<id>/delete` | 自分の投稿を削除する | 必要 | `/` へ移す | 下記の「修正と削除」を参照 |

`<id>` は投稿の番号です。写真ファイルそのものは、一覧と詳細からこの番号とは別のパスで読みます。保存名は UUID とし、利用者が付けたファイル名はパスに使いません。

## ログインしていないとき

次のリクエストは処理しません。ログイン画面へ移します。

- `GET /posts/new`
- `POST /posts`
- `POST /posts/<id>/edit`
- `POST /posts/<id>/delete`

ログインに成功したあとは、開こうとしていた画面へは戻さず、いつも `GET /` へ移します。

`GET /` と `GET /posts/<id>` はログインなしで表示します。

## 修正と削除

`POST /posts/<id>/edit` と `POST /posts/<id>/delete` は、次の順で止めます。

1. ログインしていなければ `/login` へ移す。保存も削除もしない。
2. その id の投稿がなければ、見つからない旨を出し、一覧へ戻れるようにする。保存も削除もしない。
3. ログイン中のユーザーが投稿者でなければ、投稿詳細に理由を出す。保存も削除もしない。
4. キャプション修正で 200 文字を超えていれば、投稿詳細に残り、理由を出す。空のキャプションは保存してよい。

削除がここまで通ったときは、データベースの投稿を消してから `uploads/` の写真ファイルを消します。ファイル削除に失敗したら、その失敗を記録し、成功として一覧へは移しません。

## 入力が無効なとき

無効な入力は保存しません。画面に理由を出します。

- 登録: ユーザー名が空、ユーザー名が既にある、パスワードが空。`POST /register` は登録画面に残る。
- ログイン: ユーザー名またはパスワードが違う。`POST /login` はログイン画面に残る。
- 投稿: 写真がない、JPEG と PNG 以外、5MB を超える、キャプションが 200 文字を超える。`POST /posts` は投稿作成画面に残る。

登録、ログイン、投稿、修正、削除の POST は、セッション上のトークンが一致するときだけ処理します。一致しなければ処理せず、理由を出します。
