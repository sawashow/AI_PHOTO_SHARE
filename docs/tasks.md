# 作業リスト

[ai_context.md](ai_context.md) と [coding_rules.md](coding_rules.md) に従って進めます。未完了の先頭 1 件だけを実装し、終わったら止まります。次の作業には進みません。

各作業の完了条件を満たしたら、その作業を完了にします。コメント、いいね、自動テストは、このリストの完了に含めません。

## 1. アプリの土台と user テーブル

`app.py` で Flask を起動できるようにします。`SECRET_KEY` は `.env` から読みます。Flask-Session、Flask-Login、CSRF を有効にします。`models.py` には `User` だけを作り、SQLite の外部キー検査をオンにしてからテーブルを作ります。

完了条件: アプリが起動し、`user` テーブルだけが存在する。秘密情報がコードに無い。`Post` と画面はまだ無い。

## 2. ユーザー登録

`forms.py` と登録画面を作り、`GET /register` と `POST /register` を実装します。ユーザー名、メールアドレス、パスワードを検証し、成功したら `/login` へ移します。すでにログイン中なら `/` へ移します。

完了条件: 新しいユーザーを登録できる。空、使えない文字、重複、8 文字未満のパスワードでは登録されず、登録画面に理由が出る。パスワードは再表示されない。

## 3. ログイン

`GET /login` と `POST /login` を実装します。ユーザー名は小文字の列で探し、パスワードはハッシュと比較します。

完了条件: 登録済みのユーザーがログインでき、`/` へ移る。ユーザー名やパスワードが違うときはログイン画面に残り、理由が出る。大文字小文字が違うユーザー名でもログインできる。

## 4. ログアウト

`POST /logout` を実装します。ヘッダーを、未ログインとログイン中で切り替えます。

完了条件: ログアウトすると未ログインの投稿一覧用の場所へ移る。未ログイン時のヘッダーにはログインとユーザー登録だけが出る。ログイン中は投稿作成、ログアウト、ユーザー名が出る。

## 5. post テーブル

`Post` モデルを足してテーブルを作ります。投稿者は `User` への外部キーで、削除時は `RESTRICT` です。

完了条件: `user` と `post` の 2 テーブルがある。存在しないユーザー番号の投稿は保存できない。投稿画面はまだ無い。

## 6. 写真を 1 枚投稿する

`GET /posts/new` と `POST /posts` を実装します。写真は Pillow で JPEG または PNG かを確認し、5MB までを受け、UUID などの名前で `uploads/` に保存します。データベースにはそのファイル名だけを書きます。`.gitignore` に `uploads/` を足します。

完了条件: ログイン中だけ投稿でき、成功すると `/` へ移る。未ログインは `/login` へ移る。写真がない、形式が違う、大きすぎる、キャプションが 200 文字を超えるときは保存されず、投稿作成画面に理由が出る。

## 7. 投稿一覧

`GET /` に、みんなの投稿を新しい順で出します。各投稿から詳細へ進めるようにします。写真は `uploads/` から Flask が返します。

完了条件: ログインしていなくても一覧を見られる。各投稿にユーザー名、写真、キャプション、投稿日時がある。投稿が無いときは、まだ投稿がない旨が出る。取得に失敗したときは、空の成功画面にしない。

## 8. 投稿詳細

`GET /posts/<id>` を実装します。修正フォームと削除ボタンは、次の作業まで出しません。

完了条件: ログインしていなくても 1 件を大きく見られる。存在しない id では中身を出さず、見つからない旨と一覧へ戻るリンクが出る。

## 9. 自分のキャプションを修正する

投稿詳細に、投稿者だけの修正フォームを出します。`POST /posts/<id>/edit` を実装します。写真の選び直しは出しません。

完了条件: 投稿者だけがキャプションを保存でき、成功すると同じ詳細に残る。空文字は保存できる。200 文字を超える場合は保存されない。他人の投稿と未ログインでは保存されない。投稿日時は変わらない。

## 10. 自分の投稿を削除する

投稿詳細に、投稿者だけの削除ボタンを出します。`POST /posts/<id>/delete` を実装します。データベースの行を消してから、`uploads/` のファイルを消します。

完了条件: 投稿者だけが削除でき、成功すると `/` へ移る。他人の投稿と未ログインでは削除されない。ファイル削除に失敗したときは、成功として一覧へ進まない。
